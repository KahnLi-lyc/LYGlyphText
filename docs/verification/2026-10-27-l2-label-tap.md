# L2 整段点击回调验证记录

日期：2026-10-28。基于 L1 `983833e`，分支 `codex/l2-label-tap`。契约见 [L 批次](../superpowers/plans/2026-10-27-label-refinements.md) L2。

## 交付内容

- `LYGlyphTextLabel.onTap: (@MainActor (CGPoint) -> Void)?` 与 `LYGlyphTextView(onTap:)`：点按普通文字、行间空白或内边距时回调，参数为 Label 本地坐标。
- 只在设置时安装 `UITapGestureRecognizer`，置 nil 或 SwiftUI 拆卸时移除；未设置时宿主列表的选中与滚动行为完全不变。
- 点在可发送事件的动作、可交互截断 token、交互附件或已有选区上时不回调；可选择时单击依赖长按选择先失败。

## 行为证据

- `Tests/LYGlyphTextTests/TapTests.swift`（4 项）：识别器只在设置回调时存在、拆卸清除；普通文字与内边距回调、有动作回调时动作文字不回调（无动作回调时交给 onTap）、选区存在时不回调、移出 window 不回调；截断 token 与交互附件优先；SwiftUI 传递回调。
- Demo 2.x 页新增整段点击示例，`FeatureUITests.testWholeLabelTapAndActionStaySeparate` 真实点击普通文字计数 1 次，点击“作者”只发送动作。
- 失败与修正：第一次完整回归 430 项中 429 通过，唯一失败为上述 UI 用例——示例文字把“作者”放在两行交界，“作”“者”分在两行，无障碍元素合并框的中心落在两行之间，并非动作文字，组件按契约发送了整段点击。改为把动作放在首行中间后，`l2-feature-ui-02/` 中 FeatureUITests 3 项与 TapTests 4 项全部通过。组件代码未改动。
