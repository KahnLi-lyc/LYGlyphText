# L6 Release 性能复测验证记录

日期：2026-10-29。分支 `codex/l6-perf-retest`，被测版本 main `4c58a28`（2.x G1—G7 与 L1—L5 之后）。契约见 [L 批次](../superpowers/plans/2026-10-27-label-refinements.md) L6。

## 方法

沿用 P1 的 `PerformanceMeasurementTests`（九组固定负载，Release `-O -whole-module-optimization`，`ENABLE_TESTABILITY=YES`，nearest-rank p50）。运行期间机器上其他任务占用大量模拟器，load average 在 84—367 之间，单次绝对值噪声大；因此在同一模拟器上交替运行 P1 基线 `1e787fb` 与当前版本各 3 次（base1、cur1、base2、cur2、base3、cur3），比较三次 p50 的中位数。另有一次单独运行与 P1 归档数据对比（`.build/verification/l6-release-01/`），结论一致但噪声更大，仅作参考。

## 结论

- 首次测量：100 字持平，1000／5000 字当前版本快约 7%—13%。
- 热缓存测量：约 0.2µs→0.3µs，绝对增加约 80ns，来自新增的预排版采用检查；不影响实际帧耗时。
- 位图绘制：+1%—5%，多数落在基线三次运行的波动范围内（新增的圆角背景、选区与 token 检查在无对应内容时开销很小）。
- 文档构造：短文 +3%—5%（新增链接与远程图片参数处理），长文持平。
- 结论：没有需要修复的性能回退。预排版主线程收益见 [G4 记录](2026-10-21-g4-prepared-layout.md)，本次复测的 `PreparedLayoutMeasurementTests` 仍通过。模拟器数据不代表真机。
