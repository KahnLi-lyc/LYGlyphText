## Kingfisher 与真实网络

- Demo App target 固定 Kingfisher **8.14.0**（C4 先固定 8.12.0；用户确认开发统一使用 Xcode 27 后升级）。8.13.0 起 Kingfisher 要求 swift-tools 6.2，Demo 因此需要 Swift 6.2+；组件 Package 仍为 swift-tools 6.0、零第三方依赖。
- `KingfisherImageLoader.swift` 在 Swift 6 模式下对 8.12.0 与 8.14.0 均编译通过，没有桥接相关警告。
- 临时探测测试（未提交，避免常驻测试依赖公网）在模拟器上请求 `raw.githubusercontent.com` 的 PNG：8.12.0 与 8.14.0 两轮中，内置加载器与 Kingfisher 桥接都返回按 120pt 降采样的图片（120×21.67pt@3x）；取消后的 Kingfisher 请求等待 2 秒没有回调。
- RocketSim 在本轮无法读取该模拟器的无障碍树（主屏 0 个元素、坐标点击不生效），演示页的手动切换没有截图留证，改用上面的探测测试验证运行时行为。

## 失败与处理

- 第一次完整回归（旧依赖）中 `ActionDemoUITests.testActionListActionDragCancelsWithoutBlockingScroll` 报 `kAXErrorServerNotFound`（模拟器无障碍服务无响应），与 RocketSim 读不到界面是同一环境问题；该测试本批次未改动。随后因升级 Kingfisher 中止该轮，在最终工作区重跑。
- `TruncationTokenPiecesTests.testInvalidImageSizeIsIgnored` 首次失败：断言 token 只有 1 个 run，但 Core Text 会因中文字体回退把“…更多”拆成 2 个 run。改为断言没有图片占位 run；实现不变。
